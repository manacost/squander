# Historical planning and evidence

This directory contains completed phase plans, slice checkpoints, readiness
records, and planning reviews. These files preserve implementation evidence and
historical reasoning; they are not the current framework contract.

For current behavior, start with [`specs/README.md`](../../specs/README.md),
then read the relevant capability specification under `specs/`. Use the
[decision log](../decisions.md) for durable architectural rationale and the
[candidate logs](../phase-3-candidates.md) for future work.

## Archive layout

- `phase-1/` — specification-system and verification-baseline records.
- `phase-2/` — WebGPU foundation plans and slice checkpoints.
- `phase-3/` — composition and input plans and slice checkpoints.

The archived documents retain their original contents and dates unless a link
was adjusted for the new location.
